GitHub Setup

This admin page writes only to …. The repository is fixed in site-config.json and cannot be changed here.

It needs a fine-grained GitHub personal access token restricted to that one repository:

  1. Create a fine-grained token
  2. Resource owner: ammcavoy
  3. Repository access: Only select repositories → abe_website
  4. Repository permissions → Contents: Read and write (nothing else)

Classic tokens (starting with ghp_) are rejected because they grant access to every repository on the account.
